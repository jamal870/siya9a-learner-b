# iDigi Sys Fahrschüler App

Theorie-App für Fahrschüler in Marokko mit Lernfragen, Prüfungssimulation und Fortschritt.

## Zweck

Dieses Projekt gehört zur Marke **iDigi Sys** und ist für Fahrschüler in Marokko gedacht.

Die App hilft Fahrschülern, sich auf die theoretische Führerscheinprüfung vorzubereiten.

## Funktionen

- Lernfragen
- Prüfungssimulation
- Fortschrittsanzeige
- Kategorien und Themen
- Mehrsprachige Inhalte
- Verbindung zum Fahrlehrer-Theorie-Dashboard
- Lernstatus für Schüler

## Zielgruppe

- Fahrschüler in Marokko
- Fahrschulen in Marokko
- Fahrlehrer, die Theorie-Unterricht begleiten
